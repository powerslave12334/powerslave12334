## 🚀 Sobre mí

<img align="right" width="290" src="https://media.giphy.com/media/qgQUggAC3Pfv687qPC/giphy.gif" alt="Coding Animation" />

Desarrollador y Auxiliar de Sistemas con sólida experiencia en **soporte técnico, desarrollo de software empresarial y administración de infraestructura** (Windows Server / IIS / Linux).

Actualmente trabajo en **Alcomex Transporte y Logística** como Auxiliar de Sistemas y Desarrollador, impulsando la automatización y digitalización de procesos operativos. Anteriormente colaboré en **Agua Inmaculada**, **IT Solutions Global**, **Tejido Punto Textil** y **Corporativo MMI**.

Mi objetivo es simple: escribir código limpio, construir software confiable y crecer como ingeniero de software que crea sistemas que perduran.
